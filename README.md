# Audit2Build

**サイトの診断を、改善と制作につなげる。**

Audit2Build（オーディット・トゥ・ビルド）は、WebサイトのSEO・GEO・AIOを評価し、根拠と改善の優先順位を整理するアプリです。診断後の改善案をWeb制作へ引き継ぎ、SNS・集客の振り返りにもつなげていくことを目指して開発しています。

**[アプリ画面を見る](https://app.audit2build.com/) · [サービスの紹介](https://audit2build.com/) · [開発者のnote記事](https://note.com/rob_ai_master/n/n50794212f8e4)**

## 主な機能

### サイト診断・競合比較

- 3つのAIが、共通の25項目をそれぞれ独立して評価します。
- 確認できた根拠、不足する情報、改善案を整理します。
- 対象サイトと競合3社を同じ観点で確認し、強みと改善の機会を検討します。
- 評価を混ぜたり、未実行の結果を推測で埋めたりせず、各AIの結果を個別に扱います。

### 診断からWeb制作へ

- 保存した診断と改善案を、LP Codingの入力へ引き継ぎます。
- 目的、掲載内容、トンマナ、提供素材を確認して制作へ進みます。
- Topページと追加ページ、PC・スマートフォン表示の確認、修正、承認、ZIP取得の流れを整備しています。
- HTML出力とWordPress用形式の選択を実装しています。実際のWordPressへの導入は検証中です。

### CodingとSNSの入力アシスト

入力アシストはWebAPPへ公開反映済みです。フォームを一度に埋める負担を減らすため、1項目ずつ確認して進められます。

- ON／OFFを切り替え、回答の入力・編集・スキップ・前の項目への移動ができます。
- 入力済みの内容を保持し、変更するときは確認してから反映します。
- 「Codexでアシスト開始」から、専用の相談文を新しいRoomの入力欄へ渡します。最初の送信と必要なブラウザー操作の許可は利用者が行います。
- Codexが参照できる保存済みの診断・改善内容を根拠に、文章や入力内容を相談できます。
- WebAPPの「AI自動提案」は空欄の入力候補を作るための機能です。入力アシストでは提案の意味や表現を対話で確認できます。

Codexの起動リンクからの実際の対話を含む最終確認は継続中です。スイッチをONにしただけで、登録・制作・投稿が自動実行されるものではありません。

### 既存サイトとWebAPPの最新化

今回確定した追加仕様です。既存のURLやソースをもとに、残したい内容・機能を確認しながら、見やすさと操作性を改修するモードを追加します。

- 「スマホ対応」のチェックで、改修対象を指定します。
- 「CSS／JSの整理・分離」のチェックで、スタイルと画面操作の整理を指定します。
- 通常Codingもスマホ対応を標準とし、必要なJavaScriptを扱う構成へ拡張します。
- 過去の案件・成果物を保持し、修正後は表示と動作を確認してから承認します。

**この最新化モードとJavaScript出力は、追加実装・検証の対象です。** 現在の通常CodingはHTMLとCSSの出力に対応しています。既存WebAPPの業務処理や外部接続は、元のソースと動作条件を確認して対応範囲を決めます。

### SNS・集客

地方の店舗や小売店などの、集客方針と実績を整理するための機能を追加しています。

| 機能 | 内容・現在の状態 |
| --- | --- |
| 店舗・アカウント情報 | 商圏、届けたい相手、集客目的、プロフィール、投稿文を手入力して保存。Owner環境で動作確認済みです。 |
| SNS診断 | 1つのAIを選ぶ仕組みを実装。AIの利用設定は調整中です。 |
| 投稿カレンダー | 投稿内容・予定日・CTAを登録し、計画を確認・承認。内容を修正すると承認を取り消します。承認だけでSNSへ公開されることはありません。 |
| 広告の振り返り | 広告CSVから費用・表示数・クリック数・成果数などを集計し、CTR・CPC・CPA・ROASを確認します。 |
| 売上の振り返り | 売上CSVを取り込み、売上・返金・取消を区別して集計します。 |

SNSへの自動投稿、広告アカウントの操作、POSとの自動連携、画像・動画の内容診断には、まだ対応していません。

## どのような場面に

- 自社サイトの課題を、根拠と一緒に整理したい。
- 顧客に説明しやすい診断・改善資料を用意したい。
- 診断からページの改修・制作へ、入力のやり直しを減らしたい。
- 店舗のSNS投稿計画と、広告・売上の実績を振り返りたい。

## ご利用について

アプリのTopと各入力画面は、ログインせずにご覧いただけます。保存したデータの閲覧、保存、診断・制作の実行には、利用権限のあるアカウントが必要です。一般向けの登録・提供条件・料金は調整中です。

現在はプレ公開・開発検証の段階です。AIの出力には誤りが含まれる可能性があり、根拠と事実関係を人が確認します。検索順位、AI回答への掲載、集客・売上の向上を保証するものではありません。
